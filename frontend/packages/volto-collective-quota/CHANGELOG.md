## 1.0.0 (2026-11-27)


### Feature

- Initial release: "Disk usage" in the personal tools menu, a warning banner near the limits, the disk usage page with multi-delete and link-integrity confirmation, and a Quota control panel that shows where each value comes from, with locked fields, "Rebuild usage data" and "Reset to defaults". Needs the backend add-on `collective.quota`.
